# Support

DevCatz is made by one person in Indonesia — Mahryan Rakhmatullah (Ryan N.R.) — and is free and open source. This page
says honestly what you can expect.

## Where to ask

| You want to … | Go to |
| --- | --- |
| Report a bug | **Help → Report a Bug…** in the app (it adds the version and macOS details, and can attach a screenshot), or [open an issue](https://github.com/catzoidhub/DevCatz/issues/new) |
| Suggest an idea or ask a question | **Help → Send Feedback…** in the app, or [GitHub Discussions](https://github.com/catzoidhub/DevCatz/discussions) if they are on |
| Report a security problem | **Not in a public issue** — see [`SECURITY.md`](SECURITY.md) |
| Read the docs first | [catzoid.com/docs](https://catzoid.com/docs) — FAQ and Troubleshooting answer the usual questions |
| Talk with other users | [catzoid.com/community](https://catzoid.com/community) |

## What to expect

- **Issues and bug reports** are read and answered as time allows — there is no fixed response time. Security
  reports come first, then crashes and data loss, then everything else.
- **Pull requests** are welcome — small and focused is best. Open an issue first for anything big, so nobody builds
  something that will not be merged. The first time, the CLA check asks you to sign the
  [contributor licence agreement](CLA.md); you keep the copyright of your work.
- **Labels** tell you where an issue stands: `bug`, `idea`, `question`, `needs info` (waiting for you),
  `good first issue` (a good place to start), `help wanted`, `wontfix` (with the reason).
- An issue that waits a long time for information may be closed; reopen it any time with the details.

## When the maintainer is away

DevCatz has one maintainer for now. If they cannot look after it for a while (busy, ill, on holiday), the README and
catzoid.com say so plainly with a **paused** notice and, if known, until when — instead of a repository that just
goes quiet. The apps keep working: nothing in them depends on the maintainer being online, and updates simply pause.

If a co-maintainer joins, they are named here, with what they may merge and release.

## Free, and staying free

No paid support and no Pro tier — every user gets the same help. If DevCatz saves you time and you want to help keep it
going, see [catzoid.com/community](https://catzoid.com/community) (GitHub Sponsors and more).
